# すいてるログ — 仕様

## 何を解くか
ハイブリッド勤務・時差通学で「毎日同じ電車」に乗らなくなった人が、
**自分の路線で空いている時間帯**を経験ではなくデータで選べるようにする。

企画の出どころ: ai-orchestration-dashboard でブレスト（5案を需要・実現性・差別化で採点）。
同点だった「降車アラーム」は PWA では画面ロック中に位置情報が止まる（iOS Safari）ため不採用。

## 対象
- 首都圏・関西圏の電車通勤/通学者、スマホのみで使う
- アカウント不要、データは端末内（localStorage）だけ。サーバなし

## 機能（MVP = Stage 1）
1. **ワンタップ記録**: 路線を選び、混雑度 1〜5 を押すだけ。時刻は今（`<input type=time>` で修正可、-5/-10/-15分チップ）
2. **おすすめ**: 選択中の路線・今日の曜日で、平均混雑が低い時間帯トップ3を表示（データが無い曜日は平日全体で代替）
3. **傾向ヒートマップ**: 曜日 × 15分枠の平均混雑
4. **路線管理**: 追加・削除（名前だけ。例「田園都市線 上り」）
5. **PWA**: ホーム画面追加・オフライン動作

## データ
```json
{ "routes": [{ "id": "r1", "name": "田園都市線 上り" }],
  "logs":   [{ "route": "r1", "t": "2026-10-01T07:42:00", "level": 4 }] }
```
key: `suiteru.v1`。`t` はローカル時刻（タイムゾーンなし）。

## 構成
静的ファイルのみ。ビルドなし・依存なし。
- `index.html` / `style.css` / `app.js`（UI）
- `core.js`（純粋関数: 集計・おすすめ）← `core.test.mjs` で `node --test`
- `sw.js` / `manifest.webmanifest` / `icon.svg`

## 成功条件
- iPhone/Android の幅（375px）で横スクロールなし、片手で記録が 2 タップ以内
- オフラインで起動・記録できる
- `node --test` 緑
