        記録リマインド

        平日のこの時刻にカレンダーから通知します（予定ファイルを端末のカレンダーに追加）。

        使い方

        1. 上の「変更」で自分の路線を選ぶ（エリア → 会社 → 路線 → 方面をタップ）。帰りの路線は「＋」で別に追加すると精度が上がります
        2. 乗る前に「空いてる号車」を見て、その号車に乗る
        3. 乗ったら混み具合のボタンを1回押す（号車は前回のを覚えています）。アプリの予想との答え合わせと、気分スタンプ（任意）が出ます
        4. 報告が増えるほど、号車の予想が正確になります。時刻をずらす・遅延や雨の日は「くわしく」から
        よくある質問
        乗っている間に記録できません（学校でスマホが使えない等）
        後からでも大丈夫です。「くわしく」を開いて「乗った時刻」に朝の時刻（例: 7:40）を入れてから押せば、今日のその時刻の記録になります。0時を過ぎてから前日の夜の時刻を入れた場合は前日の記録になります。
        遅延の日や試験期間の記録はどうすれば？
        「くわしく」を開いて、遅延・雨の日は記録前に「遅延」「雨」を押すと、その1回は集計に入りません（共有オンなら「遅延」の印だけは同じ路線の人に「いつもより混むかも」と伝えます）。試験期間や長期休みは「試験・休暇の期間中」にチェックを入れておくと、外すまでの記録が集計に入りません。履歴には残ります。
        データはどこに保存されますか？ 何か送っていますか？
        記録・乗換メモはこの端末の中に保存されます。「みんなと共有」をオンにしたときだけ、ランダムな番号と、路線・方面・平日か休日か・15分単位の時間帯・号車・混み具合（押した場合は気分スタンプ、遅延の印）を匿名で送ります。名前・位置情報・連絡先は送りません。共有は下の「データ」欄でいつでもオフにできます。くわしくはプライバシーポリシーへ。端末のデータを消すと記録も消えるので、「書き出す」でバックアップしてください。
        ホーム画面に置けますか？
        アプリ版はそのまま使えます。Web 版は、iPhone は Safari の共有ボタン →「ホーム画面に追加」、Android は Chrome のメニュー →「アプリをインストール」。オフラインでも使えます。
        他の人の混雑情報は見られますか？
        「みんなと共有」をオンにすると、同じ路線・方面の人の報告も合わせて「空いてる号車」を出します。共有した人は、同じ路線の報告ランキングに自動のニックネーム（例: まったりパンダ）と件数で載ります。

        データ（機種変更用）

        記録はこの端末に保存されています。
